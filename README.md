# Chrome Password Lock

Lock Google Chrome with a password on startup and after idle time.

## Features

- Password lock when Chrome starts
- Auto-lock after configurable idle time
- Manual lock via toolbar button or **Ctrl+Shift+L**
- Secure password storage (PBKDF2-SHA-256, never stored in plain text)
- Restores your previous tabs after unlock

## Install

1. Download the latest ZIP from [Releases](https://github.com/mvdworking/MyChromeLock/releases)
2. Extract the archive
3. Open `chrome://extensions`
4. Enable **Developer mode** (top right)
5. Click **Load unpacked** and select the extracted folder

## Usage

1. Open the extension **Options** and set a password (min. 4 characters)
2. Set idle timeout (1–1440 minutes)
3. Chrome will lock on startup and after idle
4. Press **Ctrl+Shift+L** or click the extension icon to lock immediately
